# Studio49

Одностраничный сайт студии S—49. Проект собран на Next.js, TypeScript и Tailwind CSS, поэтому его можно безболезненно развивать: добавлять страницы, контентные блоки, формы или подключение к CMS.

## Технологии

- [Next.js](https://nextjs.org/) 16 — фреймворк и production-сборка;
- React 19;
- TypeScript;
- Tailwind CSS 4. Основные стили текущего минималистичного экрана расположены в одном глобальном файле — это намеренно: так проще контролировать точную геометрию и анимацию знака.

## Требования

- Node.js 20.9 или новее;
- npm 10 или новее.

Проверить установленные версии:

```bash
node --version
npm --version
```

## Быстрый старт

Установите зависимости:

```bash
npm install
```

Запустите сайт в режиме разработки:

```bash
npm run dev
```

После этого сайт будет доступен по адресу [http://localhost:3000](http://localhost:3000).

## Сборка для публикации

Перед деплоем всегда проверяйте production-сборку:

```bash
npm run build
```

Для локального запуска собранной версии:

```bash
npm run start
```

Next.js статически предрендеривает текущую главную страницу, поэтому она быстрая и не требует серверной логики.

## Что и где редактировать

### Социальные сети и почта

Все ссылки на социальные сети находятся в массиве `socialLinks` в [app/page.tsx](app/page.tsx). Измените значение `href`, не меняя `label`, если надо сохранить текст из макета.

Почта для ссылки «написать» расположена там же:

```tsx
<a className="contact-link" href="mailto:s49design@yandex.ru">
  написать
</a>
```

Внешние ссылки открываются в новой вкладке. Для внутренней страницы Next.js используйте компонент `Link` из `next/link`, а не обычный тег `<a>`.

### Юридическая сноска и копирайт

Тексты футера редактируются в [app/page.tsx](app/page.tsx), внутри `<footer className="site-footer">`.

- `legal-notice` — текст сноски про Meta;
- `copyright` — строка `S—49©2026`.

Если год будет меняться автоматически, можно заменить `2026` на `{new Date().getFullYear()}`. Для текущего дизайна год зафиксирован, чтобы вёрстка точно соответствовала макету.

### Логотип и его анимация

Знак построен из `s.svg`, линии и `49.svg`. Линия не является картинкой: она рисуется элементом `.brand-line-fill` и раскрывается слева направо. Это сохраняет существующий характер анимации и позволяет линии растягиваться на любую ширину экрана.

Не заменяйте SVG частями, если не нужно менять сам знак. Чтобы заменить логотип целиком:

1. положите новые файлы в `public/`;
2. измените пути в `app/page.tsx`;
3. при необходимости скорректируйте переменные `--s-width`, `--forty-nine-width`, `--line-thickness` в `app/globals.css`;
4. выполните `npm run build`.

### Размеры и адаптивность

Ключевые величины находятся в начале [app/globals.css](app/globals.css) как CSS-переменные. Используются `clamp()`, `svh` и относительные единицы, чтобы экран сохранял композицию на широких и мобильных устройствах.

Мобильные правила находятся в `@media (max-width: 640px)`. В частности, там ссылки переносятся на новую строку, а юридическая сноска и копирайт выстраиваются вертикально.

## Добавление новой страницы

Next.js использует файловую маршрутизацию. Например, чтобы создать страницу `/about`, добавьте файл `app/about/page.tsx`:

```tsx
export default function AboutPage() {
  return <main>О студии</main>;
}
```

Общие элементы, которые должны быть на всех страницах, лучше вынести в компоненты, например `components/Header.tsx` и `components/Footer.tsx`, а затем подключить их в нужных страницах или в `app/layout.tsx`.

## Деплой

Проект готов к размещению на Vercel, а также на любой платформе, поддерживающей Next.js. Минимальный порядок действий:

1. подключите Git-репозиторий к хостингу;
2. укажите команду сборки `npm run build`;
3. укажите команду запуска `npm run start`, если хостинг требует её;
4. настройте домен и HTTPS в панели хостинга.

Переменные окружения сейчас не используются. Если позже будут добавлены ключи API, храните их в `.env.local`; этот файл уже исключён из Git.

## Перед публикацией

```bash
npm run build
```

Также вручную проверьте:

- корректность адресов Telegram, Instagram, Designers и LinkedIn;
- адрес для «написать»;
- текст юридической сноски;
- отображение на мобильном устройстве;
- favicon и метаданные страницы.
